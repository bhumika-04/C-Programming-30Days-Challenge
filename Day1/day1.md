# Day 1: Introduction to C Programming

Hello Everyone! 👋

Day 1 of my 30 Days of C challenge and honestly I am super excited to start this! I picked C because everyone says it is the foundation of everything and I wanted to understand how programming actually works at a lower level.

### Key Learnings:

1. **What is C?**
   - C is called a middle-level language because it has features of both high-level and low-level languages.
   - It was developed by Dennis Ritchie in 1972. That is older than most things I use daily!

2. **Structure of a C Program:**
   - Every C program starts with `#include <stdio.h>` — this gives access to input/output functions.
   - The `main()` function is where the program actually starts running.

3. **My First Program:**
   - Wrote the classic Hello World program. Simple but it felt satisfying to compile and run it!

4. **Why C?**
   - C is fast, efficient, and very close to how the hardware works. A lot of operating systems and embedded systems are built in C.

### Code Snippet - Hello World:

```c
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}
```

## What I Learned

- C fundamentals: data types, operators, control flow, functions
- Memory management: pointers, malloc/free, dynamic allocation
- Data structures: arrays, linked lists, stacks, queues, trees, hash tables
- File handling and error handling
- How to write and organize multi-file C programs

---

## How to Run

```bash
gcc filename.c -o output
./output
```

For math functions:
```bash
gcc filename.c -o output -lm
./output
```
